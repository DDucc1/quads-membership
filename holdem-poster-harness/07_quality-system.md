# 07 — 퀄리티 보장 시스템 (Design Quality System)

> 목적: "어떤 테마/컨셉으로 요청해도 **실사용 가능한 일정 수준 이상**의 포스터가 나오게" 만드는 규칙 집합.
> 원칙: **스타일은 자유롭게 차용하되, 아래 9개 품질 항목(QP)은 무조건 충족**해야 출고된다.
> 04_evaluation-rubric(겹침/넘침 같은 기계적 합격)이 "**불량 0**"이라면, 이 문서는 "**매력 일정선 이상**"을 보장한다.

---

## 0. 품질 등급 (서비스 출고 기준)

| 등급 | 의미 | 출고 |
|---|---|---|
| **S** | 9개 QP 전부 만점 + 디자인 디바이스 2개 이상 적용 | 프리미엄 |
| **A** | 9개 QP 전부 합격(≥3/4) | ✅ 자동 출고 가능선 |
| **B** | 1~2개 QP 미달 | 리페어 후 재평가 |
| **C** | 3개 이상 미달 또는 04-rubric 불량 | 출고 금지 |

> 서비스(무승인 자동 출고)는 **A 이상**만 통과시킨다. B 이하는 자동 리페어 루프.

---

## 1. 9개 품질 항목 (QP) — 항목별 분류

각 항목은 **[불변]**(스타일 무관 항상 지킴) + **[자유]**(스타일별 응용 허용)로 나뉜다.

### QP1. 초점·위계 (Focal & Hierarchy) — "한눈에 딱"
- [불변] 0.5초 안에 읽히는 **1순위 정보 1개**가 있어야 한다(보통 **상금/GTD** 또는 **이벤트명**).
- [불변] 시각 무게 순서: `1순위(초대형) > 2순위 > 3순위 > 본문`. 인접 단계 크기비 ≥ 1.4배.
- [불변] 화면을 흘끗 봤을 때 시선이 **한 곳에 먼저 꽂혀야** 한다(동급 크기 요소 2개가 경쟁 금지).
- [자유] 1순위를 타이틀로 할지 상금으로 할지는 컨셉별 선택.

### QP2. 가독성·대비 (Readability)
- [불변] 본문 대비 ≥ 4.5:1, 헤드라인 ≥ 3:1. 밝은 배경 위 텍스트는 **스크림/섀도 필수**.
- [불변] 텍스트는 배경의 **저주파(밋밋한) 영역**에 놓는다. 고대비 패턴 위 직접 배치 금지.
- [자유] 글자색(라이트/다크 반전)은 배경 밝기에 맞춰 선택.

### QP3. 여백·리듬 (Whitespace & Rhythm)
- [불변] 세이프존 준수 + 요소 간 **호흡 간격**(밴드 갭 ≥ 2%H).
- [불변] 화면이 균등하게 꽉 차거나(저밀도 금지) 너무 비지 않게(과밀 금지) — **밀도 40~70%** 목표.
- [불변] 수직 리듬에 **강약**을 준다(히어로는 넓게, 정보부는 촘촘). 전 구간 등간격 = "딱딱함" → 감점.
- [자유] 중앙정렬/좌측정렬 등 정렬 컨셉.

### QP4. 정렬·그리드 (Alignment)
- [불변] 모든 요소는 공통 그리드/앵커에 정렬. 어긋난 가장자리 0.
- [불변] 표/스탯 셀 폭·정렬·간격 일관.
- [자유] 그리드 분할(중앙축/2단/비대칭) 컨셉.

### QP5. 컬러·테마 일관성 (Color)
- [불변] **악센트색 1~2종**으로 절제. 그 외는 명도 단계.
- [불변] 텍스트 악센트색 = 배경 테마색과 **동일 계열**(통일감). 충돌색 금지.
- [불변] 골드/실버 등 메탈릭은 그라데이션으로(평면 단색 금지).
- [자유] 팔레트(20테마 등) 자유.

### QP6. 타이포 디테일 (Typography)
- [불변] **폰트 페어링**: 디스플레이(헤비/콘덴스드) + 본문 고딕 2종 이내. 한/영 역할 분리.
- [불변] 캡스·라벨에는 **자간(tracking)** 부여. 큰 제목은 자간 타이트.
- [불변] 숫자/금액 포맷·콤마 일관. 단위는 본문보다 작게.
- [자유] 이탤릭/아웃라인/그라데이션 등 제목 처리.

### QP7. 디자인 디바이스 (Design Devices) — "디자인 포인트 살리기"
> 밋밋함을 막고 "디자인된 느낌"을 주는 장치. **최소 2개 이상** 적용 권장(S등급 필수).
- 코너 프레임(L자 장식) / 리본·배너(BUY-IN 등 강조) / 구분 디바이더(스페이드·다이아 모티프) /
  키커 바(소제목 강조선) / 뱃지·씰(트로피·공식) / 광선·파티클 오버레이 / 큰 숫자 워터마크.
- [불변] 디바이스는 **가독·초점을 방해하지 않는 선**에서. 텍스트와 겹쳐 가독 저하 = 무효.
- [자유] 어떤 디바이스를 쓸지, 몇 개 쓸지.

### QP8. 마감 디테일 (Finish)
- [불변] 핵심 요소에 **깊이감**(섀도/글로우/이너섀도) 부여 — 평면 붙여넣기 느낌 금지.
- [불변] 배경에 **비네팅 + 미세 노이즈/그레인**으로 인쇄물 질감(밴딩 방지).
- [불변] 패널·박스는 **테두리 또는 미세 광택**으로 면 분리.
- [자유] 글로우 강도·질감 종류.

### QP9. 브랜딩 정합 (Brand)
- [불변] 로고/스폰서/푸터 정위치 + 단색 정규화 + 높이 통일.
- [불변] 입력(일시·장소·금액·주소)과 **1:1 일치**, 오탈자 0.
- [자유] 로고 배치 디테일.

## 2. "스타일 차용해도 무너지지 않게" — 운영 메커니즘

서비스에서 클라이언트가 임의 컨셉을 던져도 A등급을 보장하는 3중 안전장치:

1. **골격 고정(L1)**: 레이아웃/세이프존/밴드(03_fixed) → 구조 붕괴 원천 차단.
2. **품질 항목 강제(이 문서 QP1~9)**: 스타일 레이어에 적용되는 체크. 스타일이 바뀌어도 QP는 상수.
3. **자동 리페어 루프**: 렌더 후 QP 자가채점 → 미달 항목만 수정(폰트/대비/간격/디바이스 추가) → 재렌더. A 미만이면 출고 보류.

```
요청(테마/컨셉/내용) → 골격 주입(L1) → 스타일 토큰(L2) → 콘텐츠(L3)
   → 렌더 → [04-rubric 불량검사] → [07-QP 품질채점]
   → A이상? 예: 출고 / 아니오: 리페어 루프(최대 N회) → 그래도 미달: 보류+사유로그
```

## 3. 디자인 디바이스 카탈로그 (QP7 구현체)

| 디바이스 | 용도 | 적용 밴드 |
|---|---|---|
| `corner_frame` | 프리미엄 프레이밍 | 세이프존 4모서리 |
| `buyin_ribbon` | 참가조건 강조 | A5 / B5 |
| `suit_divider` | 섹션 구분 + 포커 정체성 | 히어로 하단 |
| `kicker_bar` | 소제목/지명 강조 | 타이틀 주변 |
| `seal_badge` | 트로피/공식/회차 | A0 |
| `mega_watermark` | 배경 거대 숫자/심볼 | 배경층 |
| `light_streak` | 동적 광선 | 배경층 |

각 디바이스는 테마 악센트색을 따르며, 켜고 끌 수 있다(입력 `devices: [...]`).
