# 06 — 신규 포스터 의뢰 정보 수령 리스트 (INTAKE FORM)

> 신규 포스터를 요청할 때 **운영자에게 받아야 하는 정보 체크리스트**.
> ✅필수 / 🔶선택 / ⚙️자동(엔진이 채움, 안 줘도 됨) 으로 구분.
> 이 양식만 채우면 `schema/game-input.schema.json` 으로 바로 매핑되어 동일 품질로 렌더링된다.
> **여기 없는 항목(여백·정렬·폰트위계·대비 등)은 전부 ⚙️자동 — 운영자가 신경 쓸 필요 없음.**

---

## STEP 0. 어떤 종류의 포스터인가 (아키타입)  ✅필수

| 선택 | 아키타입 | 언제 |
|---|---|---|
| ☐ 단일 이벤트 홍보 1장 | **A** | 가장 흔함. Challenge/Collaboration 등 |
| ☐ 블라인드 스트럭처·프라이즈 포함 | **B** | 구조표를 보여줘야 할 때 |
| ☐ 여러 이벤트 일정표(시리즈) | **C** | DREAM SERIES 같은 전체 일정 |

> 모르겠으면 비워도 됨 → 이벤트 개수/구조표 유무로 엔진이 자동 판정.

---

## STEP 1. 공통 필수 정보 (A·B·C 전부)  ✅필수

| # | 항목 | 예시 | 비고 |
|---|---|---|---|
| 1 | **이벤트명(타이틀)** | `CHALLENGE` / `Collaboration` / `MAIN EVENT` | 영문/한글 가능 |
| 2 | **보증 방식 + 금액** | `GTD 30,000,000` 또는 새틀라이트면 `WIN YOUR SEAT @160,000` | 둘 중 택1 |
| 3 | **일시** | `26.07.04 (토요일) 오후 2시` (숫자형) 또는 `7월 4일 토요일 오후 2시` (자연어형) | 둘 다 OK |
| 4 | **장소(지점명)** | `대전 POD 스타디움` | 타이틀/푸터에 사용 |
| 5 | **주소(도로명)** | `대전광역시 서구 둔산로 100, 5층` | 푸터 |
| 6 | **BUY-IN(참가 조건)** | `1 Challenge Ticket` / `1 Challenge OR 20PP OR 20FP` / `20 SEED` | 다중옵션 OK |
| 7 | **테마(분위기/배경 소재)** | 불꽃 / 바다·등대 / 우주 / 맹수 / 우드·콜라보 / 추상광(시리즈) | 아래 프리셋 참고 |

### 테마 프리셋 (7번 선택지)
`flame_blue`(푸른불꽃) · `golden_door`(황금문) · `ocean_teal`(바다/등대/파도) ·
`space_blue`(우주) · `animal_dark`(맹수+연기) · `wood_warm`(우드/콜라보) ·
`series_red`/`series_purple`/`series_blue`(시리즈 추상광)
> 원하는 사진/무드 이미지를 첨부해도 됨. 없으면 이벤트 성격에 맞춰 엔진이 추천.

## STEP 2. 스탯 4종  ✅필수 (값 없으면 그 칸은 자동 제거 후 재균등)

### 아키타입 A 스탯
| 항목 | 예시 |
|---|---|
| **ENTRY** (참가/엔트리) | `120 Entry++` |

### 아키타입 B 스탯
| 항목 | 예시 |
|---|---|
| **STACK** (스택) | `50,000 Chips` |
| **END of REG** (레지 종료) | `15LV 시작 전` |
| **DURATION** (레벨 시간) | `30 Mins` / `40/30 Mins` / `30(20) Mins`(터보) |
| **ENTRY** | `955++` / `8 TO 1`(새틀라이트) |

## STEP 3. Notice for Player 문구  🔶선택 (안 주면 공통 기본문 사용)

- **공통 기본 풀**(자동 포함, 빼고 싶은 것만 알려주세요):
  레지스트레이션 마감 / 빅블라인드 엔티 / 엔티 불감소 / TDA 준수 / 부정행위 처벌 /
  9max 진행 / S-Ticket 동의 후 참가 / 신분증 본인확인 / 세금신고 / NEW PLAYER CARD 지급
- **이 이벤트만의 추가 문구**(있으면 알려주세요):
  - 예) `타임뱅크 차등 지급 (브레이크 별 얼리버드 추가 지급)`
  - 예) 콜라보: `행사 흥행시 S-Ticket or PP or FP 선택 지급`
  - 예) 새틀라이트: `@160,000 1SEAT 획득 시 챔피언십 1좌석`

## STEP 5. 옵션 요소  🔶선택 (해당될 때만)

| 항목 | 언제 | 예시 |
|---|---|---|

## STEP 6. 아키타입 B 추가 정보 (구조표 포스터일 때만)  ✅조건부필수

| 항목 | 형식 | 예시 |
|---|---|---|
| **블라인드 레벨표** | LV / SB / BB / ANTE / BLIND 행 목록 | `1, 100, 200, 200, 30` … |
| **브레이크/리무브 위치** | 어느 레벨 뒤에 무엇 | `LV2 뒤 Break 10min / Remove 100 Chips` |
| **레지 종료 표시** | END of REG 위치 | `LV15 뒤 *END of REG` |
| **프라이즈표** | 🔶 RANK / PRIZE (없으면 좌측=스탯리스트) | `1st 40,000,000` … |

> 엑셀/표 형태로 주셔도 됩니다. 엔진이 2-컬럼 그룹·BREAK 강조행·콤마 정렬을 자동 처리.

## STEP 7. 아키타입 C 추가 정보 (시리즈 일정표일 때만)  ✅조건부필수

| 항목 | 예시 |
|---|---|
| **시리즈명** | `DREAM SERIES` |
| **기간** | `대전 ANPT 07.10 - 07.11` |
| **총 보증액** | `300,000,000 TOTAL GUARANTEED` |
| **이벤트 행 목록** | 날짜 / 시간 / 이벤트명(#번호) / BUY-IN / GTD / ENTRY / STACK / LEVEL / ENTRY CLOSE |

예시 1행: `07.10 FRI | 18:00 | #2 MAIN EVENT DAY1 | MAIN 1 TICKET OR 50FP | ₩150,000,000 | 500++ | 40,000 | 30 | 12LV`

## ⚙️ 엔진이 자동 처리 (운영자가 줄 필요 없는 것)

캔버스 규격·세이프존(여백)·밴드 배치·정렬·폰트 종류와 위계·대비/명암 보정·
글자 오토핏(겹침/넘침 방지)·빈 칸 재균등·표 컬럼 폭·zebra·BREAK 강조행·
스폰서 로고 단색 정규화·QA 게이트 검수 — **전부 자동.**

## 📋 복붙용 의뢰 템플릿 (운영자에게 이 한 덩어리만 채워달라고 요청)

```
[아키타입]  A / B / C  (모르면 비움)
[테마]      (불꽃/바다/우주/맹수/우드/시리즈 중, 또는 첨부 이미지)
[이벤트명]  
[악센트]    (선택: in OOO / Chapter.N)
[보증/금액] GTD 00,000,000   (또는 WIN YOUR SEAT @000,000)
[일시]      YY.MM.DD (요일) 오후 H시
[장소]      OOO 스타디움
[주소]      
[BUY-IN]    
[스탯] ENTRY:        STARTING:        LATE REG:        BLIND:
       (B형) STACK:  END of REG:      DURATION:        ENTRY:
[Notice 추가문구] (없으면 비움)
[스폰서] 주관사:      협력사:      후원사:      장소:
[옵션]  트로피뱃지 Y/N · 포맷프리픽스(8MAX 등) · 콜라보 파트너
[B형] 블라인드표 / 프라이즈표  (첨부 또는 표)
[C형] 시리즈명 / 기간 / 총보증 / 이벤트 일정표
```

> 이 템플릿을 채워 보내주시면 → JSON 매핑 → 렌더 → QA 게이트 → 최종 포스터(PNG) 산출.
