# [병렬 트랙 프롬프트] 포스터 퀄리티 상향 전담 세션

> 이 문서 전체를 새 세션의 첫 메시지로 붙여넣으면 퀄리티 트랙 작업이 시작됩니다.
> (시스템/기능 트랙은 별도 세션에서 병렬 진행 중 — 충돌 방지 규칙 필수 준수)

---

## 미션

당신은 홀덤 토너먼트 포스터 자동생성 시스템의 **비주얼 퀄리티 전담 디렉터**다.
레이아웃 골격과 서비스 기능은 이미 완성되어 있다. 당신의 유일한 임무는:

> **같은 입력, 같은 골격에서 — 산출물의 "보이는 퀄리티"를 실제 대회사 포스터와 구분 불가능한 수준까지 끌어올리는 것.**

기능을 만들지 마라. 파이프라인을 바꾸지 마라. 오직 픽셀 퀄리티만 높여라.

---

## 0. 시작 절차 (순서대로)

1. `holdem-poster-harness/HANDOFF.md` 를 읽고 전체 맥락 파악.
2. 환경 복원:
```bash
cd holdem-poster-harness
pip install Pillow numpy
bash assets/fetch_fonts.sh
python3 bg_generate.py all && python3 bg_animals.py
```
3. 기준선 확인 — 아래 3개가 전부 `QC TOTAL: ALL PASS` 여야 시작 가능:
```bash
python3 make_animals.py && python3 make_layouts.py && python3 make_examples.py
```
4. **새 브랜치 생성**: `claude/poster-quality-<임의suffix>` (기존 `claude/holdem-poster-harness-I58wz` 에서 분기).
   시스템 트랙과 같은 브랜치에 커밋 금지.

- 모든 변경 후 **3개 러너 QC ALL PASS 회귀 필수** (러너 파일 자체는 수정 금지, 실행만).

## 2. 퀄리티의 정의 (무엇을 높이는 것인가)

합격 기준: **"이거 AI가 만들었네"라는 티가 없고, 실제 대회사가 디자이너에게 발주한 결과물로 보일 것.**

현재 상태의 정직한 약점 (= 당신의 공격 목표, 우선순위 순):

1. **배경 아트의 깊이 부족** — 절차 생성 배경이 "그라데이션+도형" 티가 남음.
   → 레이어 깊이(전경 파티클/보케/미세 텍스처/광원 상호작용), 노이즈 다층화, 색 수차·필름 룩 등.
2. **타이틀·머니 타이포가 평면적** — 단색/단순 그라데이션.
   → 메탈릭(골드/실버/크롬) 텍스처, 베벨/이너섀도, 에지 하이라이트, 미세 反사. 단 가독성 훼손 금지.
3. **엠블럼/로고 완성도** — 동물 문장(울프문/이글 등)은 좋은 시작이나 디테일이 얕음.
   → 라인 정교화, 이중 스트로크, 질감. 새 동물/모티프 추가 환영.
4. **인쇄급 해상도 부재** — 현재 1080폭 화면용.
   → 전역 스케일 팩터(예: `SCALE=2.5`)로 좌표·폰트·블러 일괄 확대 렌더 옵션 구현(기본값 1.0 유지 — 시스템 트랙 호환).
5. **색 대비 자동검증 부재(R5)** — 구현은 금지(qc.py 시스템 소유). 대신 밝은 배경 위 텍스트가 생기지 않도록 스크림/그레이딩을 강화하고, R5 규칙 설계안만 보고서로.
6. **테마 확장** — 현재 21+5종. 시즌/컨셉 테마(네온 나이트, 럭셔리 마블, 사이버, 한국적 모티프 등) 추가 환영. `THEME_SPECS`/`THEME_ACCENT` 등록 방식 준수.

### 품질 판단 기준 (07_quality-system.md의 QP 9항목 준수)
초점·위계 / 가독·대비 / 여백·리듬 / 정렬 / 컬러 절제(악센트≤2) / 타이포 페어링 / 디자인 디바이스 / 마감(깊이·그레인) / 브랜딩 정합.

## 3. 작업 방법론 (반복 루프)

한 번에 한 요소만 공략하고, 매 사이클을 다음 루프로:

```
① 목표 요소 선정(예: 머니 타이포 메탈릭)
② 구현 → 대표 3장 렌더(A/B/C 각 1)
③ 자가 검수: 풀사이즈 육안(확대 크롭 포함) + 3러너 QC ALL PASS
④ 전/후 비교 몽타주 생성 → 사용자에게 전달(개선점 1줄 설명)
⑤ 커밋(작게, 요소 단위) → 다음 요소
```

- 육안 검수 시 반드시 **풀사이즈로 크롭 확대**해서 볼 것 (몽타주 축소본만 보고 판단 금지).
- 개선이 애매하면 전/후 두 버전을 나란히 보여주고 사용자 선택을 받아라.
- 실패한 실험은 되돌리고 기록만 남겨라 — 어중간한 개선을 쌓지 마라.

## 4. 하드 제약 (위반 = 실패)

- QC ALL PASS를 깨는 커밋 금지. 화려함보다 **가독성이 항상 우선**.
- 레퍼런스 실브랜드(POD/ANPT/SEEDKET 등) 사용 금지 — 데모는 가상 브랜드만.
- 외부 네트워크는 GitHub만 허용 — 스톡 이미지/폰트 CDN 불가. 폰트는 google/fonts 레포에서만 추가.
- 특정 데모 1장만 좋아지는 하드코딩 금지 — 개선은 **모든 테마/레이아웃에 일반화**되어야 함.
- 시스템 트랙 브랜치(`claude/holdem-poster-harness-I58wz`)에 푸시 금지.
