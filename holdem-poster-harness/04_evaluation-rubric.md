# 04 — 평가모델 / QA 게이트

> 요구사항 #2(명암·폰트 등 디자인 품질 기준 명확) + #5(모든 평가모델 통과한 것만 최종).
> **게이트 원칙: PASS/FAIL은 이분법. 단 하나라도 FAIL이면 "초안", 전 항목 PASS여야 "FINAL".**
> 점수는 우선순위/리페어 순서를 정하기 위한 보조 지표일 뿐, 합격 판정은 체크리스트가 한다.

---

## TIER 0 — 자동 리젝트 (하나라도 해당 시 즉시 FAIL, 점수 무의미)

| 코드 | 검사 | FAIL 조건 |
|---|---|---|
| R0-1 | 글자 겹침 | 텍스트가 다른 텍스트/박스와 0px 초과 중첩 |
| R0-2 | 세이프존 침범 | 어떤 글리프라도 x∉[6,94]% 또는 y∉[3,97]% |
| R0-3 | 밴드 경계 침범 | 텍스트가 소속 밴드 밖으로 돌출 |
| R0-4 | 오탈자 | 입력 JSON 문자열과 산출 텍스트 불일치(예 '임요일') |
| R0-5 | 표 셀 깨짐 | 셀 텍스트 줄바꿈/잘림/셀선 침범 |
| R0-6 | 단위·콤마 불일치 | 금액/숫자 포맷이 포스터 내에서 불일치 |
| R0-7 | 빈 슬롯 노출 | 플레이스홀더·빈 열·`null` 노출 |
| R0-8 | 필수 블록 누락 | 로고/BUY-IN/스탯/Notice/스폰서/푸터 중 누락 |

> TIER 0는 요구사항 #1을 기계적으로 보장하는 층이다. 통과 못하면 다른 평가를 볼 필요도 없다.

## TIER 1 — 정량 품질 채점 (각 0~5, 가중 합산 100점)

### 1. 가독성·명암 (Contrast) — 가중 ×5 (25점)
- C-1 본문 텍스트/배경 대비 ≥ **4.5:1** (WCAG AA). 미달 시 0~2점.
- C-2 타이틀/배경 대비 ≥ **3:1**.
- C-3 밝은 배경 영역 위 텍스트는 음영 패드 또는 반전 처리 적용.
- 만점: 모든 텍스트가 어느 화면 밝기에서도 즉시 읽힘.

### 2. 타이포 위계·정렬 (Typography) — ×4 (20점)
- T-1 role 크기 위계가 시각적으로 명확(타이틀이 가장 크고, 캡션이 가장 작음).
- T-2 영문/한글 폰트 역할 분리 준수.
- T-3 동일 밴드 내 베이스라인/그리드 정렬 일관.
- T-4 자간/행간이 욱여넣기(음수 자간) 없이 자연스러움.

### 3. 레이아웃 균형 (Layout) — ×4 (20점)
- L-1 밴드 간 갭 일정, 시각 리듬 안정.
- L-2 좌우 여백 대칭(또는 의도된 좌정렬 일관).
- L-3 B아키타입 좌(프라이즈)↔우(블라인드) 무게 균형.
- L-4 4열 스탯/표 컬럼 폭 균등 또는 내용기반 정렬.

### 4. 컬러·테마 일관성 (Color/Theme) — ×3 (15점)
- K-1 팔레트가 토큰 프리셋 범위 내, 악센트색 ≤ 2종.
- K-2 배경 소재의 주조색과 악센트색이 조화(REF-04 호랑이 오렌지=악센트).
- K-3 강조행/뱃지 색이 전체 톤과 충돌하지 않음.

### 5. 브랜딩·정보 정확성 (Brand/Info) — ×2 (10점)
- B-1 POD 로고/시리즈 뱃지/스폰서 4구역 정위치.
- B-2 스폰서 로고 단색 정규화·높이 통일.
- B-3 일시/장소/금액/주소가 입력과 1:1 일치.

### 6. 시선 흐름·무게중심 (Hierarchy) — ×2 (10점)
- H-1 금액(GTD/총보증)이 타이틀 다음 무게중심.
- H-2 시선 흐름이 위→아래(또는 의도된 Z/F) 자연스러움.

**합격선: TIER 0 전부 PASS + TIER 1 총점 ≥ 90 + 모든 항목 ≥ 3점.**
(어느 한 항목이라도 2점 이하면 총점과 무관하게 리페어 대상.)

## TIER 2 — 아키타입 적합성 (해당 타입만)

- A형: 트로피 뱃지(있으면)·BUY-IN·4열 스탯·Notice 전부 단일 시선축에 정렬.
- B형: 블라인드표 2-컬럼 그룹화, BREAK/END 강조행, 헤더 반복, 프라이즈표 정렬(또는 스탯리스트 대체).
- C형: 날짜 그룹 병합, 9컬럼 줄바꿈 없이 수용, zebra 가독.

---

## 리페어 루프 프로토콜

```
검수 → FAIL 항목 수집 → 우선순위(TIER0 > 저점항목) → 해당 밴드만 수정
     → 재렌더 → 재검수  (최대 3회)
3회 후에도 FAIL → 배포 금지, FAIL 항목 명시하여 사람 검수 요청
```

리페어 시 **FIXED 골격은 절대 건드리지 않는다.** 폰트 스텝다운/음영 패드/재균등/약어 등 `01_master-prompt` STEP4 수단만 사용.

## QA 체크리스트 (출고 전 복붙용)

```
[ ] R0-1 겹침 없음        [ ] R0-2 세이프존 OK     [ ] R0-3 밴드내 수용
[ ] R0-4 오탈자 없음      [ ] R0-5 표 셀 정상      [ ] R0-6 포맷 일관
[ ] R0-7 빈슬롯 없음      [ ] R0-8 필수블록 완비
[ ] C 대비 ≥ 기준 (≥3점)  [ ] T 타이포 위계 (≥3점)
[ ] L 레이아웃 균형 (≥3점) [ ] K 컬러 일관 (≥3점)
[ ] B 브랜딩/정확 (≥3점)  [ ] H 무게중심 (≥3점)
[ ] TIER1 총점 ≥ 90
[ ] TIER2 아키타입 적합
→ 전부 체크 시에만 "FINAL" 선언
```
