# learn/ — 레퍼런스 학습 체계

> 목적: 사용자가 지속 제공하는 "괜찮은 포스터"를 **반복 학습**해, 구조적 체계성과
> 디자인 유연성이 양립한 채로 산출물의 세련된 완성도를 끌어올린다.
> 원칙: HANDOFF §4-9 하네스 경계 준수 — 구조·텍스트는 규율(측정 가능 검사),
> 배경·특수 디자인은 자유 영역. 학습은 **절대값 모방이 아니라 관계·기법의 축적**이다.

## 파이프라인 (레퍼런스 1건이 들어오면)

```
① 수집   사용자가 이미지 제공 (채팅/폴더/URL)
② 기록   learn/refs/rNNN-*.md 생성 — 관찰만 적는다 (craft-points.md의 C-ID로 태깅)
③ 증류   반복 관찰(2건 이상)된 기법 → learn/distilled.md에 패턴 후보로 승격
④ 승인   패턴 후보를 사용자에게 제시 → 승인된 것만 구현 대상 (HANDOFF §4-3)
⑤ 구현   craft_lab.py에서 실험 → 검증되면 정식 렌더러로 졸업 (불변 규칙 준수)
⑥ 실습   실제 포스터 1장 제작 + learn/practice/pNNN.md 리포트 (적용 포인트 명시)
⑦ 피드백 사용자 피드백 → craft-points.md 가중치/기준 갱신 → ⑥ 반복
```

## 파일 규약

| 파일 | 역할 | 갱신 시점 |
|---|---|---|
| `craft-points.md` | **완성도 판별 포인트 체계** (C-ID 목록, 측정 기준 포함) | 새 기법 관찰·피드백 반영 시 |
| `refs/rNNN-*.md` | 레퍼런스 1건(또는 동일 계열 묶음)의 관찰 기록 | 레퍼런스 수집 시 |
| `distilled.md` | 패턴 보드: 후보 → 승인 → 구현 → 졸업 상태 추적 | 증류·승인·구현 시 |
| `practice/pNNN.md` | 실습 리포트: 적용 C-ID, 자평, 사용자 피드백 | 실습 1회당 1개 |

## 학습이 생성에 반영되는 경로 (3층)

1. **크래프트 컴포넌트** — 재사용 가능한 시각 기법 함수 (`craft_lab.py` → 졸업 시 render_editorial.py).
   예: 고스트 타이틀, 네온 글로우, 호라이즌 플레어. *유연성의 원천 — 조합 자유.*
2. **렌더 정책** — 컴포넌트를 언제/어디에 쓰는지의 기본값 (렌더러별 상수·테마 스펙).
   예: "GTD 숫자는 코어 백색 + 액센트 halo", "표 헤더는 액센트 반전". *체계성의 원천.*
3. **QC 규율** — 관계·비율로 측정 가능해진 완성도 포인트만 qc.py R룰로 승격.
   예: R4 크기 일관성. 측정 불가한 감각 항목은 craft-points.md 체크리스트로만 유지.

## 하지 않는 것

- 레퍼런스 실브랜드(POD/ANPT/CHEEZEE/MANNERS/WFP/MSL 등) 이름·로고 사용 — 가상 브랜드만.
- 이미지 픽셀 복제·트레이싱 — 기법(관계·비율·처리)만 추출한다.
- 절대값 규율화 — "어떤 색/폰트를 써라"는 규칙으로 만들지 않는다 (HANDOFF §4-9).
