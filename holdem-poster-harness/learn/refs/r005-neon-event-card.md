# r005 — 네온 이벤트 카드/스케줄 계열 (WFP 이미지 검색 11장)

- 수집: 2026-07-30 "WFP 홀덤" 이미지 검색 (대형 토너 시리즈 홍보물)
- 유형: **3) 스케줄·이벤트** — 이벤트별 네온 컬러 코드 카드 + 일정 그리드
- 무드: 방송급 프로덕션(중계 화면과 통일된 아이덴티티)

## 관찰

- **C4/C1** 이벤트마다 단일 네온색 배정(MAIN=마젠타, HIGHROLLER=블루, MASTER=민트, LADIES=핑크…) — 색 = 이벤트 식별자
- **L1** 이벤트명 네온 글로우 — 코어 백색 + 색 halo, 배경도 동계열 저명도(C2)
- **T3/T5** TOTAL GTD 초대형 디스플레이 숫자 + 보조 정보 소형
- 스케줄 그리드: 날짜 행(요일 헤더) → 시간/이벤트명/티켓/GTD/듀레이션 열 — 열 정렬 엄격(S4)
- **S1(변형)** 날짜 구분은 액센트 텍스트, 이벤트 행은 저대비 행 스트립(S2)
- **F3** 트로피/금속 질감 오브제가 유일한 사진 요소 — 나머지는 타이포+색
- 랭킹 GTD 표(1~20위)를 좁은 폭에 우측 정렬로 압축 — 문장형이 아닌 미니 표

## 채택 판단

- C형(시리즈 스케줄)의 발전 방향: 이벤트별 색 코드 배정 정책 — 렌더 정책 후보
- 네온 글로우(L1)는 r001과 함께 최다 관찰 — 구현 우선순위 최상 확정
