# 완성도 판별 포인트 체계 (Craft Points)

> 제1목적 "세련된 완성도"를 세부 판별 가능한 단위로 분해한 목록.
> 각 포인트는 **관찰 근거(레퍼런스)** 와 **판별 기준(가능하면 측정형)** 을 갖는다.
> 상태: ☐ 미구현 · ◐ craft_lab 실험 · ● 정식 렌더러 반영 · ★ QC 규율 승격
> 출처 표기는 learn/refs/의 rNNN 기록 번호.

## 사용법

- 레퍼런스 기록(refs/rNNN) 작성 시 관찰된 포인트를 C-ID로 태깅한다.
- 실습 리포트(practice/pNNN)는 "적용한 C-ID + 어떻게"를 명시한다.
- 사용자 피드백으로 기준이 바뀌면 이 문서를 갱신하고 상태를 조정한다.
- 새 기법이 2개 이상 레퍼런스에서 관찰되면 새 ID를 발급한다.
