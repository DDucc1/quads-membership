## 2. 핵심 불변 규칙 (건드리면 안 되는 것)

- **fit_common**: 동일 역할 요소(스탯 값/라벨, 표 셀, 불릿)는 공통 크기 하나로 — 열마다 제각각 축소 금지.
- **theight**: 세로 간격 계산은 measure()가 아니라 theight()(어센더 포함) — 겹침 버그의 근원이었음.
- **rect_blend**: RGBA 캔버스 반투명 사각형은 반드시 이걸로(ImageDraw.rectangle은 알파 SET → 불투명 순백 버그).
- **브랜드는 데이터**: `logo_mark`/`logo_word` 필드 — 하드코딩 금지(레퍼런스 브랜드 배제 요구).
- QC를 통과 못 하면 출고하지 않는다(무승인 자동 발행의 전제).

## 3. Codex QC 게이트 (`qc.py`)

렌더 중 모든 텍스트 bbox를 자동 계측(ImageDraw 전역 패치 + text_img/vtext/frost 마킹) 후 검사:

| 규칙 | 내용 |
|---|---|
| R1 CANVAS | 캔버스 이탈 |
| R2 SAFE | 세이프존(좌우6%/상하3%) 침범 |
| R3 OVERLAP | 텍스트 상호 겹침(양축 3px 초과) |
| R4 SIZE | 같은 행 인접 텍스트의 어중간한 크기 차(1.04~1.75x). **frost 패널이 다르면 비교 제외**(패널 인지) |

사용: `import qc; A0,EA,EB,EC = qc.load()` (이 순서 필수 — 패치 후 렌더러 로드) → `qc.run(name, W, H, fn)`.
한계: 색 대비(R5)는 아직 육안 — 백로그 참조.

## 4. 사용자가 확정한 방향 (의사결정 기록)

1. **B형(블라인드+상금표)이 기본 베이스** — 나머지는 특수 요청. 단일 양식 고수 X → V1~V5 변형 제공.
2. **레퍼런스 브랜드(POD/ANPT 등) 완전 배제** — 가상 브랜드로 데모. 어떤 요구든 **현재 수준이 최소 퀄리티**.
3. **규칙은 Claude가 추출 → 사용자가 승인**. 규율 없는 업계이므로 우리가 하우스 스타일을 정의.
4. **인쇄급 초고해상**이 최종 화질 목표(현재 1080폭은 화면용 — 백로그).
5. 서비스 형태: 사장님이 **위저드에 입력만** 하면 QC 통과본이 무승인 자동 발행. 형태 규정이 아니라 **품질 규정**(불변식+게이트)로 자유도 확보.
6. C형 그리드 폰트 상향(12→최대 19px), 위저드는 이모지 없는 전문 톤.
7. **(2026-07-15) 서비스 제공 맥락 4종 확정** — 사장님 사용 흐름 시뮬레이션 결과: ① 최초 온보딩(1회) ② 정규 토너먼트(최빈, 복제→바뀐 것만 수정, 목표 30초) ③ 특별 이벤트(풀 입력→시안 3종 비교) ④ 부분 수정(발행본 요소 클릭→해당 요소만 재렌더·재검수). **"언제든 요청에 따라 수정 가능한 유연함"이 전 맥락 필수 요건.** *(③의 "시안 3종 비교" 플로우는 10항 입력 기획으로 대체됨 — 현행은 에디터 내 구도 토글. 별도 비교 화면 복원 여부는 미결.)*
8. **(2026-07-15) 디자인 유사성·취향 이슈 해소 = A+B 전략 확정** — A: 브랜드 킷(문장/컬러/타이포 무드를 데이터로 주입, 매장 고유 시드로 배경 변형) + B: 온보딩 취향 캘리브레이션(A/B 선택 3문항→서체·밀도·구도 개인화). C(상권 배타 배정)는 스케일 단계에 설계만. → 여러 업체가 써도 디자인이 겹치지 않게 하는 구조적 해법.
9. **(2026-07-16) 하네스 경계 확정** — 구조·텍스트 표기에는 **15~20개의 정확하고 명확한 규율을 강하게** 걸어도 된다(정보 위계 순서, 대비, 최소 폰트, 겹침/잘림/세이프존, 크기 통일, 정렬 그리드, 여백 리듬 등 = 관계·비율 검사). 단 **배경·특수 디자인은 규율 밖 무제한 자유 영역** — 여러 디자인 컨셉이 자유롭게 반영돼야 하며, 고해상 무료 이미지 활용·직접 제작 모두 허용. 규칙은 절대값(어떤 색/폰트/구도)을 검사하지 않는다.
10. **(2026-07-16) 입력 기획 확정** — 매번 입력은 필수 4(대회명/일시/바이인/개런티)+훅 1로 고정, 날짜·시간·금액은 칩 선택(타이핑 최소화), 블라인드 구조·상금 분배는 프리셋 자동 구성(접힌 상태), 추가 요소는 "슬롯" 개념(후원 로고 레일, 게스트 히어로, QR — 설계된 자리에만, 슬롯 포함 재검수). 모르는 값 건너뛰어도 진행(발행 시 기본값). 역할 분담: **레이아웃 계열 확장 = 퀄리티 트랙 담당.**

## 4.5. 통합 앱 프로토타입 (`demos/app.html`, 2026-07-15)

**중요한 피벗**: 처음에 맥락별 스텝-위저드 데모 4개를 만들었으나 사용자가 전면 리젝 ("디자인부터 흐름까지 다 별로, 다 갈아엎어") → **통합 앱 프로토타입 하나**로 재구축. 4개 데모 파일은 삭제됨(git 히스토리에는 남음).

사용자가 확정한 형태 원칙:
- **스텝 위저드 금지** — 단계 넘기기 없이 한 화면에서 입력 즉시 포스터 반영
- **낱개 시연 페이지 금지** — 홈(내 포스터 그리드) → 에디터 → 발행이 하나의 앱 경험으로 이어져야 함
- 설명 박스·안내 문구 최소화, 모든 동작 2클릭 이내

`demos/app.html` 구성 (의존성 0 단독 HTML, 다크 차콜+골드 프로덕트 UI):
- **홈**: 내 포스터 그리드(hover 시 "이어받아 새로"/"수정"), 상단 넛지 배너("이번 주 위클리 아직 없음 → 이어받기")
- **에디터**: 좌 폼 · 우 대형 포스터 실시간 미리보기. 포스터 글자 클릭 → 해당 입력으로 이동. 구도 3종(센터/스플릿/볼드) 썸네일 토글
- **칩 입력 (2026-07-16)**: 날짜는 실제 캘린더 기반 칩(다가오는 토/일/금+다음 주), 시간·바이인·개런티는 프리셋 칩+직접 입력 전환. 대회명은 기존 포스터 자동완성. 블라인드 구조·상금 분배는 "자동 구성" 접힌 패널
- **추가 요소 슬롯 (2026-07-16)**: 후원 로고 레일 구현 — 이름 추가/삭제, 최대 4개 규격, 포스터 하단 전용 슬롯에 단색 워드마크 자동 정렬. 게스트 히어로·QR은 다음 단계 표기
- **배경 컨셉 8종 (2026-07-16)**: 딥/스포트/레이/보케/하프톤/기하/네온/펠트(그레인) — 하우스 팔레트를 받아 전혀 다른 무드 생성. "배경은 제한 없음, 계속 추가됨" 원칙을 UI에 명시. 실서비스에선 사진·일러스트 컨셉으로 확장
- **이어받기**: 날짜 자동 +7일 범프. 맥락 2(정규)와 4(부분 수정)가 이 흐름에 자연 통합됨
- **발행**: 빈 필드 기본값 자동 채움 → QC 스캔라인 스윕 → 토스트 → 홈 복귀·카드 추가. 수정 재발행은 카드 교체
- **하우스 스타일 모달**: 문장 6종·팔레트 6종·서체 3종 — 바꾸면 홈·에디터 전체 즉시 반영 (A 전략)

## 7. 주의사항

- 이 원격 환경은 **네트워크가 GitHub만 허용** — 외부 스톡/폰트 CDN 불가. 이미지가 필요하면 채팅 업로드 또는 레포 경유.
- `make_examples.py`에는 아직 레퍼런스 브랜드(POD 등)가 남아 있음(회귀 테스트용 구데이터) — 대외 데모에는 `make_animals.py`/`make_layouts.py` 사용.
- 환경 재시작 시 pip 패키지·폰트·배경이 사라짐 → 0절 복원 절차 실행.
- **로컬 Windows PC에서 작업 시**: `python3` 대신 `python`, 실행 전 `PYTHONUTF8=1` 필요(qc.py의 ✅ 출력이 cp949에서 크래시). 폰트는 fetch_fonts.sh 대신 PowerShell Invoke-WebRequest로 받아도 됨. 2026-07-15 로컬 복원 완료 상태(렌더 15장 전부 QC PASS 확인).
