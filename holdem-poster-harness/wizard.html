새 포스터 제작 요청

필요한 정보만 순서대로 입력하시면 됩니다. 레이아웃 구성, 서체·정렬, 규격 검수는 시스템이 자동으로 처리하며, 검수를 통과한 결과물만 발송됩니다.

02 대회 정보기본 5항목
03 게임 구조수치·구조표

05 추가 요소선택
06 확인·발행요약
STEP 01 — 분위기예상 소요 10초

포스터의 분위기를 선택하세요

하나만 선택하면 배경 아트, 포인트 컬러, 서체 조합이 함께 결정됩니다.

자동 처리 선택한 분위기에 맞춰 배경·포인트 컬러·서체·표 스타일이 일괄 구성됩니다.
STEP 02 — 대회 정보예상 소요 1분

대회 내용을 입력하세요

평소 공지에 쓰시는 내용 그대로면 충분합니다. 표기 형식은 자동으로 정리됩니다.

자동 처리 금액은 천 단위 구분·GTD 표기로, 일시는 포스터 표기 규격으로 변환됩니다.
STEP 03 — 게임 구조예상 소요 30초–2분

구조표 포함 여부를 선택하세요

선택에 따라 포스터 형식이 자동으로 결정됩니다. 형식 이름을 알고 계실 필요는 없습니다.

붙여넣기만 하면 표 정렬, 브레이크 행 강조, 단 분할까지 자동으로 조판됩니다.

자동 처리 값이 비어 있는 항목은 제외하고 남은 항목을 균등 배치합니다. 구조표는 규격에 맞춰 자동 조판됩니다.
STEP 04 — 브랜딩최초 1회만 · 이후 자동 적용

매장 브랜드 정보

한 번 저장하면 다음 요청부터는 이 단계가 생략됩니다.

로고가 없을 때 워드마크 생성에 사용됩니다.

로고 업로드 · PNG 투명 배경 권장 — 없으면 이니셜 기반 워드마크가 자동 생성됩니다
자동 처리 스폰서 로고는 단색으로 정규화되고 높이가 통일되어 하단 영역에 정렬됩니다.
STEP 05 — 추가 요소전부 선택 사항

이번 대회의 추가 요소

해당 사항이 없으면 그대로 다음으로 진행하세요. 기본 구성만으로도 완성도가 보장됩니다.

대표 사진매장 · 트로피 · 게스트 사진을 배경으로 합성합니다
트로피 강조공식 트로피 수여 문구와 엠블럼을 추가합니다
초청 게스트게스트 프로필 사진과 이름을 배치합니다
안내문 추가기본 안내문 외 매장 규정을 추가합니다
자동 처리 업로드된 사진은 밝기를 분석해 텍스트 가독성이 유지되도록 자동 보정됩니다. 미첨부 시 선택한 분위기의 아트 배경이 적용됩니다.
STEP 06 — 확인 · 발행예상 소요 10초

요청 내용 확인

발행 후 약 30초 내에 완성본이 전달됩니다.

분위기울프 미드나잇 대회명WOLF PACK 보장 상금25,000,000 GTD 일시26.09.05 (토) 밤 9시 장소루나 홀덤 라운지 참가 조건1 Wolf Ticket 형식홍보형
규격 검수 4항목(경계·여백·중첩·서체 일관성)을 통과한 결과물만 발송됩니다.
발행 시: 인쇄용 원본과 SNS 규격본이 함께 생성되어 등록된 연락처로 전달됩니다. 분위기 변경 재발행은 1회 클릭으로 가능합니다.

흐름 설계 기준

입력 부담은 최소로, 결과 품질은 시스템이 보증하는 구조입니다.

원칙적용
분위기를 먼저요청자의 첫 관심사인 "어떻게 보일지"를 첫 화면에 배치. 색·서체·배경이 한 번에 결정됩니다.
디자인 용어 배제형식(A/B/C), 세이프존, 서체 등 내부 용어는 노출하지 않습니다. "구조표 포함 여부"라는 질문 하나로 형식이 결정됩니다.
필수 입력 최소화필수는 대회 정보 5항목과 수치 4항목뿐입니다. 나머지는 전부 선택이며, 빈 값은 자동 재배치됩니다.
표는 붙여넣기스프레드시트 복사 → 붙여넣기로 끝. 정렬과 강조 행 처리는 자동입니다.
브랜딩 1회 저장두 번째 요청부터 STEP 04가 생략되어 재요청은 2분 내에 완료됩니다.
무승인 자동 발행규격 검수를 통과한 결과물만 발송되므로 관리자 확인 절차가 없습니다. 미통과 시 자동 수정 후 재검수합니다.
