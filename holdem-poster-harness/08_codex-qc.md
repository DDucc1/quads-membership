# 08 — Codex QC 레이어 (규격 검증 리뷰어)

> "글자 삐져나감·규격 이탈·겹침은 절대 있으면 안 된다"를 **말이 아니라 코드로** 보장하는 층.
> 구현: `qc.py`. 렌더 파이프라인의 마지막 게이트이며, **위반 1건이라도 있으면 출고 금지(FAIL)**.

---

## 동작 원리

렌더러가 그리는 **모든 텍스트의 실제 바운딩박스를 자동 계측**한다. 렌더러 코드는 수정하지 않는다 —
`ImageDraw.text` 전역 패치 + 텍스트 이미지(`text_img`/`vtext`) 합성 추적으로 좌표를 수집한다.

```
렌더 실행 ──▶ 텍스트 박스 전량 기록 ──▶ 규칙 검사 ──▶ PASS → 출고
                                          └▶ FAIL → 위반 목록 출력, 출고 금지
```

- 메인 캔버스에 그려지는 것만 기록 (스크래치 캔버스 노이즈 제외)
- `draw_ls`(문자 단위 드로우)는 같은 행 런(run)으로 병합 후 검사
- 섀도 등 동일 요소 중복 드로우(IoU>0.8)는 한 개로 취급

## 규칙

| 코드 | 검사 | FAIL 조건 |
|---|---|---|
| **R1 CANVAS** | 캔버스 이탈 | 박스가 캔버스 밖 (허용오차 1.5px) |
| **R2 SAFE** | 세이프존 침범 | 좌우 6% / 상하 3% 침범 |
| **R3 OVERLAP** | 텍스트 상호 겹침 | 두 텍스트가 양축 3px 초과 침투 |

## 사용

```python
import qc
rp, EA, EB, EC = qc.load()      # 계측 패치 → 렌더러 로드 (이 순서 필수)
violations = qc.run("포스터명", EB.W, EB.H, lambda: EB.render(data, LV, "out.png"))
# violations == [] 일 때만 출고
```

`make_examples.py`가 이 게이트를 통과하는 기준 구현이다.

## 이 레이어가 실제로 잡아낸 버그 (회귀 방지 기록)

1. **어센더 간격 버그** — `measure()`(타이트박스)로 간격을 계산했지만 실제 드로잉은
   어센더 기준이라, 큰 타이틀 아래 라벨이 ~10px씩 파고듦. → `theight()` 도입, 간격 계산 전면 교체.
2. **세로 레일 세이프존 이탈** — A형 좌측 레일 텍스트가 x=25(세이프 65 미만)에 배치. → 마진 재배치.
3. **B형 BUY-IN ↔ 거대 머니 충돌** — 같은 행 좌/우 배치라 긴 BUY-IN 문자열에서 겹침. → BUY-IN 전용 행 신설.
4. **푸터 하단 이탈** — 스폰서/주소 2행이 세이프존 하단을 넘음. → 하단 재구성(좌 스폰서 3구역 / 우 지점 2행).
5. **반투명 SET 버그(육안 검수)** — RGBA 캔버스에 `rectangle(alpha)`는 블렌드가 아니라 픽셀 SET →
   zebra가 불투명 순백으로 찍혀 흰 글자 실종. → `rect_blend()` 도입.
