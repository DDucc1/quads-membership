01 — 정보 계층

사장이 매번 새로 아는 정보는 4개뿐이다

포스터에 들어가는 정보는 15개가 넘지만, 그걸 다 입력받는 순간 서비스가 귀찮아진다. 기준은 우선순위가 아니라 정보의 출처 — 사장 머릿속에만 있는 것만 묻고, 나머지는 시스템이 이미 안다.

계층요소출처 · 처리
매번 입력① 대회명  ② 일시  ③ 바이인  ④ 개런티 (+선택: 한 줄 훅)사장 머릿속 — 유일하게 매번 묻는 것. 칩 선택으로 타이핑 최소화
프리셋 승계블라인드 구조, 스타팅 스택, 레벨 시간, 리엔트리·레이트 등록 규정온보딩 때 등록한 "정규 구조" 자동 적용, 접힌 패널에서 수정 가능
자동 산출상금 분배(1~N위), 채널별 사이즈, 레이아웃·서체·규격개런티와 하우스 스타일에서 시스템이 계산
매장 자산매장명, 문장(엠블럼), 컬러, 서체 무드, SNS, 주소온보딩 1회 등록 — 이후 전 포스터에 자동 주입
손님의 주목 우선순위는 개런티 중심이고, 포스터의 렌더 크기 위계는 규율 R8이 "개런티 ≥ 대회명 > 일시 > 바이인"으로 고정한다 (두 개념은 다르다 — 주목은 마케팅, 위계는 렌더 규격). 입력 순서는 사장의 말 순서를 따른다 — "토요일에 위클리 하는데, 바이인 5만에 300 걸었어."
02 — 입력 플로우

사용 상황 4가지를 시뮬레이션하면 흐름이 정해진다

주 3–5회 · 사용량 80%

반복 대회

홈에서 "이어받기" → 날짜 자동 +7일 → 확인 → 발행.

입력 0–2개 · 30초
월 1–2회

새 이벤트

필수 4 칩 선택 + 훅 1 입력. 구조는 자동 구성.

입력 5개 · 2분
수시

발행 후 수정

포스터에서 해당 글자 클릭 → 고침 → 재발행(게시물 교체).

입력 1개 · 15초
최초 1회

온보딩

매장 자산 + 정규 블라인드 구조 등록. 여기만 무겁고 이후 평생 가벼움.

5분 · 1회
홈내 포스터 그리드, 이번 주 빠진 대회 넛지
이어받기 / 새로2클릭 이내 진입
단일 화면 에디터칩 선택 → 즉시 미리보기. 스텝 없음. 모르는 값 건너뛰기 허용
검수 · 발행빈 값 기본 채움 → 규격 검수 → 채널별 이미지

막힘 제거 원칙: 날짜·시간·금액은 타이핑이 아니라 칩 선택(다가오는 토/일 자동 제안, 금액 프리셋), 대회명은 자동완성, 구조·분배는 "자동 구성됨" 한 줄로 접힘. 어떤 값도 진행을 막지 않는다.

03 — 추가 옵션

옵션은 스티커가 아니라 슬롯이다

특수 목적 요소는 필수 플로우에 절대 노출하지 않고 "+ 추가 요소" 한 곳에만 둔다. 각 옵션은 레이아웃에 미리 설계된 자리(슬롯)에만 들어가며, 슬롯이 채워지면 검수가 그 슬롯을 포함해 다시 돈다 — 그래서 옵션을 더할수록 완성도가 올라간다.

옵션슬롯 위치완성도 장치상태
후원사 로고하단 로고 레일최대 4개, 단색 워드마크 통일, 자동 정렬 — 덕지덕지 방지구현됨 (v2)
초대 이벤트 (게스트·인플루언서)사진형 히어로얼굴 세이프존 검수, 적응형 스크림 (렌더 경로 기구현)다음 단계
예약 QR하단 코너최소 크기·대비 검수다음 단계
시리즈·서킷 뱃지상단 뱃지시리즈 공통 아이덴티티 승계 (Day1/포인트)설계
프로모션 (바운티·위성전)강조 밴드개런티 밴드와 위계 충돌 자동 조정설계
04 — 하네스 경계

구조·텍스트는 규율 19, 배경은 무제한

품질 하한을 지키려면 하네스가 강해야 하지만, 강할수록 결과물이 비슷해진다는 딜레마 — 해법은 하네스를 약하게 하는 게 아니라 검사 대상을 나누는 것. 규칙은 관계·비율·순서·수치만 검사하고, 절대값(어떤 색·어떤 그림·어떤 무드)은 검사하지 않는다. v2 — Codex+Claude 4렌즈 교차검증 반영: 콘텐츠 정합군 신설, 시각 무게 균형 제외, 스크림은 렌더 정책으로 이관.

강한 규율 — 구조·텍스트 표기

19개 · 관계·비율·수치로 정의 (선결: 역할 태깅)

이 안에서는 타협 없음. 위반 시 출고 금지.

  • 렌더 검증 — 기구현 (qc.py)
  • R1캔버스 이탈 금지
  • R2세이프존 침범 금지 (좌우 6% · 상하 3%)
  • R3텍스트 상호 겹침 금지 (겹침 > 캔버스 폭 0.3%)
  • R4같은 행 인접 텍스트의 어중간한 크기 차 금지 (1.04–1.75x 대역)
  • 콘텐츠 정합 — 신설
  • R5필수 4(대회명·일시·바이인·개런티) 실재 검증 — placeholder·빈값·기본값 표식 발행 금지, 각 값은 지정 라벨과 결합
  • R6수치 정합 — 상금 분배 합 ≥ 개런티(보장 미달 = 허위 광고 금지), 블라인드 레벨 단조 증가
  • R7날짜–요일 일치 (캘린더 대조)
  • 위계
  • R8렌더 크기 위계 고정 — 개런티 ≥ 대회명 > 일시 > 바이인 > 구조표 > 부가
  • R9최상위 강조 요소는 포스터당 1개
  • 가독성
  • R10최소 폰트 하한 — 캔버스 높이 대비 비율 기준 (해상도 독립, 표·푸터 포함)
  • R11배경–텍스트 대비 하한 4.5:1 — 텍스트 bbox 하위 픽셀만 샘플링, 배경 자체는 심사하지 않음
  • 타이포
  • R12정보 영역 서체는 하우스 킷 2종만 — 장식 레터링·타이포 아트는 자유 영역으로 면제
  • R13자간·행간 허용 밴드 (디스플레이 타이트, 라벨 레터스페이싱)
  • R14숫자는 tabular 정렬 (금액·블라인드·시간)
  • 정렬 · 여백
  • R15레이아웃이 선언한 그리드에 스냅 (허용오차 명시)
  • R16여백 리듬 — 섹션 간격 등비 ±20%
  • 표기 · 브랜드
  • R17금액·시간 표기 통일 — 만/억 단위 자동 승급 · 24시
  • R18블라인드 표 최소 형식 — LV·SB·BB 필수, Ante·레벨시간 컬럼 확장 허용
  • R19브랜드 요소 규격 — 상대 순서·최소 식별 크기·타 요소 충돌 금지 (절대 위치는 레이아웃 소관)

무제한 자유 — 배경·특수 디자인

규율 밖 영역 · 계속 확장

어떤 컨셉이든 등록될 수 있다. 하네스는 이 영역을 건드리지 않는다.

  • 배경 아트
  • 생성파라메트릭 배경 — 그라디언트·레이·보케·하프톤·기하·네온·그레인… 시드로 무한 변형
  • 사진고해상 무료 이미지 소스 활용 (매장 사진, 스톡) — 글자 가독은 R11이 검사, 스크림 보정은 렌더 정책
  • 일러스트동물 문장, 커스텀 아트, 시즌 컨셉 — 직접 제작 등록
  • 특수 디자인
  • 모티프그래픽 모티프·질감·조명 연출 자유
  • 무드미니멀부터 맥시멀까지 — 취향 축이 결정
  • 유일한 접점
  • 검수배경 위에 얹힌 글자가 R10–R11을 통과하는지만 본다 (텍스트 bbox 하위 픽셀만 샘플링). 배경 자체는 심사하지 않는다
  • 렌더 정책가독 미달 영역의 스크림 자동 삽입은 규율이 아니라 렌더러 불변식(fit_common·theight·rect_blend와 동급) — 검사 전에 보정한다
"다 비슷해 보인다"의 실체는 색이 아니라 실루엣(구도)이다. 사람 눈은 구도를 먼저 인지한다. 따라서 다양성 투자 순서는 ① 레이아웃 계열 확장 ② 배경 모티프 계열 다변화 ③ 컬러 — 레이아웃 확장은 퀄리티 트랙이 담당한다.
05 — 다양성 3축

같은 펍은 일관되게, 다른 펍은 다르게, 매번 조금씩 새롭게

축 1 · 펍 단위 고정

아이덴티티

브랜드 킷 — 문장·컬러·서체 무드. 온보딩에서 확정되어 전 포스터에 주입.

효과 같은 펍은 일관, 다른 펍은 상이
축 2 · 포스터 단위 변동

표현

배경 컨셉·시드, 레이아웃 변형, 그래픽 모티프 — 무제한 자유 영역.

효과 같은 펍 안에서도 매번 조금 다름
축 3 · 사장 단위

취향

밀도·장식성·구도 성향 — 온보딩 캘리브레이션으로 기본값 개인화.

효과 취향이 없는 펍도 자기 결이 생김

세 축의 조합 공간(컬러 계열 × 문장 × 서체 × 레이아웃 × 배경 컨셉 × 시드)에서 두 펍이 같은 결과를 받을 확률은 구조적으로 0에 수렴한다. 같은 상권 중복은 상권 배타 배정(운영 정책)으로 마감 — 스케일 단계 과제.

06 — 로드맵 · 검증

실행 순서와 유료 서비스 성립 검증

완료① 칩 중심 에디터 — 날짜·시간·금액 칩, 자동완성, 자동 구성 패널, 빈 값 기본 채움 (프로토타입 v2)
완료② 슬롯 1호 후원 로고 레일 — 최대 4개, 단색 정렬, 전용 슬롯 (프로토타입 v2)
분담③ 레이아웃 계열 확장 — 퀄리티 트랙 담당 (메탈릭 타이포·보케 레이어 진행 중)
